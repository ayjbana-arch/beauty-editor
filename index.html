설정 가이드
구글 블로거 시작 (무료 · 5분)
1
blogger.com 접속 → 구글 계정으로 로그인
2
새 블로그 만들기 → 주소 설정 (예: amore-editor.blogspot.com)
3
설정 → 기본 → 블로그 ID 복사 (숫자 코드)
4
console.cloud.google.com → 새 프로젝트 → Blogger API 활성화 → API 키 발급
5
위 설정 탭에 Blog ID + API Key 입력 → 저장 → 자동 업로드 가능!
구글 블로거 애드센스 연동
1
블로거 대시보드 → 수익 메뉴 → 애드센스 신청
2
글 12~15개 쌓인 후 신청 (이 툴로 자동 생성하면 금방 채워짐)
3
승인 후 광고 자동 삽입 → 방문자 발생하면 수익 시작
링크 선택 기준
1
아모레 브랜드 제품 → 에딧샵 우선 (수수료 25%로 가장 높음)
2
여러 곳에서 팔 때 → 가격 비교란 입력 → AI가 자동으로 "어디가 이득" 문구 생성
3
올리브영에만 있는 제품 → 올영 큐레이터 (7%)
4
쿠팡에만 있거나 가장 싸면 → 쿠팡 파트너스 (3%)
5
지그재그에 있는 뷰티/패션 제품 → 지그재그 링크
플랫폼별 업로드 방식
B
구글 블로거 — API 자동 업로드 버튼 → 완전 자동
N
네이버 블로그 — 복사 버튼 → 붙여넣기
T
티스토리 — 복사 버튼 → 붙여넣기 (API 2024년 종료)
